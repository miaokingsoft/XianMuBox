# 闲沐盒子 XianMuBox

> **别人的桌面摆件只能看时间，你的这块屏——播你的新闻、盯你的股票、放你的电台、还能给你讲故事。**
>
> 一台开源、可自己动手做的个人智能桌面信息终端——ESP32-S3 + MicroPython，240×240 彩色小屏 + 三颗按键。插件式架构（一个功能 = 一个模式插件），开箱 SoftAP 扫码配网，浏览器 Web 页配置全部个人数据。

`ESP32-S3` · `MicroPython` · `240×240 彩屏` · `3 按键` · `插件式架构` · `CC BY-NC 4.0`

本仓库发布**可直接刷写的固件**与**设备端完整文件树**，以及全套中文功能文档；不含 PC 端构建工程。

## 一、它是什么

市面上的桌面小屏不少，大多数只能看时间。闲沐盒子想做的事更具体一点：**把你散在手机各个 App 里的信息，收拢到桌前一屏。**

- **个人**——它显示的是*你的*东西：你的自媒体账号、你的持仓、你的 AI 服务余额、你关心的网站数据。账号与密钥都存在自己设备上。
- **智能**——开机自动联网校时，数据自动刷新，整点自动播报，闹钟自动响；不用你盯着，到点它自己动。
- **桌面**——240×240 彩色小屏，USB 供电，摆在桌角不占地方，安静的时候是真安静。
- **信息终端**——13 个功能插件（含一套本机设置），三颗按键全搞定，屏幕上的内容按一下就能翻页。

## 四、快速上手

> **你需要准备**：一台闲沐盒子（或照[第七节清单](#七硬件清单)自己做一台）+ 一根 USB 数据线 + 一台电脑。

### ① 刷固件

固件在 [Releases](../../releases) 下载：`firmware-mp3dec.bin`（v1.29-romfont-mp3dec，现役版，MD5 见 Release 说明，版本履历见 [docs/固件版本履历.md](docs/固件版本履历.md)）。

```bash
# 进下载模式：按住 BOOT → 短按 RST → 松开
esptool --port COMx --chip esp32s3 --baud 460800 \
        --before default-reset --after hard_reset write-flash 0x0 firmware-mp3dec.bin
```

> ⚠️ 若执行过 `erase_flash`，文件系统被清空，刷机后必须完成下方「② 推送设备文件」；仅刷 app 分区则保留原有文件。

### ② 推送设备文件

`device-files/` 是设备端完整文件树（MicroPython 程序 + 字库 + 图标 + 网页），用单连接批量推送脚本一次写入：

```bash
pip install pyserial
python tools/fast_push.py COM5 device-files /
```

- 全程单连接、设备不软复位，约 2.6MB 几分钟推完，结束后自动重启进应用
- ⚠️ 推送会把设备端 `settings.json` 覆盖为本仓库的**空骨架**——升级旧设备前先备份设备配置：`python -m mpremote cp :settings.json ./settings.backup.json`

### ③ 首次配置

1. **配网**：设备 WiFi 未配置时开机自动进入配网页——屏幕显示二维码，手机连接热点 **`XianMuBox-<SN末4位>`**（开放网络），自动弹出配网页（或浏览器访问 `http://192.168.4.1/`），选择 WiFi 输入密码，成功后自动进主菜单。详见 [docs/WiFi配网功能文档.md](docs/WiFi配网功能文档.md)。
2. **Web 配置页**：浏览器访问 `http://<设备IP>/`，可配置：WiFi、各服务商 API Key（DeepSeek / 硅基流动 / Kimi / 心知天气 / 股票数据源等，自己注册自己填）、闹钟、新闻档期等。仓库内 `settings.json` 只是结构骨架，**不含也不需要任何密钥**。
3. 配置持久化在设备本地 `settings.json`，与仓库骨架无关。改完即存，设备端一秒左右生效。

> 已经联网的设备更省事：屏幕上点开「HTTP 服务」会显示一个二维码，手机扫一下就能打开 Web 配置页。

## 五、按键规范

整个设备只有三颗按键，规则统一，不用记：

| 按键 | 内容浏览类页面 | 菜单 / 列表类页面 |
|---------|--------------|-----------------|
| **A** | 翻页（下一张 / 下一项） | 选中项上移 |
| **B** | 主操作（刷新 / 确认 / 机选 / 进详情…） | 确认 / 执行 |
| **C** | 退出返回主菜单 | 选中项下移（退出走页面内「退出」项） |

短按为主，**全项目基本不用长按**，仅两处例外（各自文档内已标注）：

- **控刷视频**：非运行态 A 长按 = 切换 BLE 设备（全项目唯一保留的长按功能）
- **摩斯电码**：移植套件内部 B 长按 = 返回子菜单

全文见 [框架架构设计文档](docs/框架架构设计文档.md)。

## 六、功能可用性一览

设备内置的「闲沐盒子云平台」接入依赖**作者私有云服务的激活密钥**，公开产物中该密钥为空——**云平台功能默认不可用**，其余本地功能不受影响：

| 类别 | 功能 | 你需要准备 |
|---------|------|-----------|
| ✅ 开箱即用 | 网络时钟、背单词、摩斯电码、控刷视频、本机设置 | 无 |
| 🔑 需自备 Key / 接口 | 模型余额、股票实时行情、项目仪表、天气、股票 AI 预测 | 自己注册的服务商 Key、自有站点 API |
| ☁️ 需云端激活 | 网络电台、听老故事、整点新闻的平台数据源、云端开奖回落 | 闲沐云激活密钥（公开产物中为空） |

> 本地机选、文字降级等回落逻辑不受云端可用性影响：整点新闻在 WAV 缺失时自动降级为文字浏览，云端开奖不可用时本地机选照常工作。

## 九、目录结构

```
├── device-files/        设备端文件树（推送到设备 / 根目录）
│   ├── main.py / boot.py      程序入口
│   ├── framework/             框架层（settings/http_server/provision/cloud/audio...）
│   ├── modes/ menus/          功能模式插件与菜单
│   ├── font/ icons/ pic/      字库与 UI 素材
│   ├── www/                   Web 配置页
│   └── settings.json          空骨架（结构示例，个人配置经 Web/配网写入设备）
├── PCB/                 嘉立创 EDA 专业版 PCB 工程（三板分体）
├── tools/fast_push.py   单连接批量部署脚本
└── docs/                功能文档、架构文档、接线表、PCB 制板说明、固件版本履历
```

> `docs/` 中的文档描述项目内部 `src/` 源码工程的结构与实现，本公开仓仅含运行产物；文档中的按键规范、接口定义、配置结构对使用者完全有效，源码路径以内部工程为准。
