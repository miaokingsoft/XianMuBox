# 项目目录结构说明

> 适用版本：XianMuBox v1.2  
> 更新日期：2026-09-01  
> 目的：作为新加入开发者的目录导览，标注每个目录/文件的用途、可修改性与典型场景

---

## 1. 顶层目录

```
XianMuBox/
├── AGENTS.md                  # AI/开发者全局约定（文档同步规则，必读）
├── README.md                 # 项目入口文档（必读）
├── src/                      # 源码目录（开发期编辑）
├── devices/                  # 设备档案（引脚/屏幕/硬件能力）
├── profiles/                 # Profile 配置（功能组合）
├── tools/                    # PC 端构建/部署/测试工具
├── firmware/                 # 固件定制源与产物（romfont C 模块 + mp3dec MP3 解码模块 firmware/mp3dec/ + LVGL 绑定包装层 firmware/lvgl/ + 全量汉字 .bin + release/ 固件归档；版本履历 doc/固件版本履历.md，不部署设备）
├── tests/                    # 自动化测试（静态分析）
├── doc/                      # 项目文档（本目录所在）
├── legacy/                   # 旧版代码归档（仅供参考，不修改）
├── build/                    # 构建产物（gitignore，自动生成）
└── photo/                    # 实物照片（手动维护）
```

| 目录/文件 | 修改频率 | 说明 |
|-----------|----------|------|
| `README.md` | 每次发版 | 项目门面，包含目录结构、构建/部署/测试指令 |
| `src/` | 高 | 主要源码开发区 |
| `devices/` | 低（新增设备时） | 每种硬件一份档案 |
| `profiles/` | 中 | 功能组合编排（决定每次 build 的内容） |
| `tools/` | 低 | 维护 PC 端构建/部署/测试流水线 |
| `tests/` | 中 | 配合源码变更同步更新 |
| `doc/` | 中 | 配合代码变更同步更新 |
| `legacy/` | 永不 | 历史归档 |
| `build/` | 自动 | `python tools/build.py` 生成，**不要手动修改** |
| `photo/` | 低 | 实物照片 |

### 2.1 顶层文件

| 文件 | 维护者 | 说明 |
|------|--------|------|
| `boot.py` | 手动 | 初始化装配：硬件初始化 → settings.json 加载 → 亮度应用 → 开机动画 → NTP（固定北京时区）→ 返回（v1.27+ USB CDC 时序要求，主循环在 main.py） |
| `main.py` | 手动 | 应用主循环：菜单 → 模式分发 → 模块回收（raw REPL 软复位会跳过本文件直接落回 REPL，deploy 依赖此特性） |
| `config.py` | **自动** | build.py 生成；指向 `devices.<X>` 档案 |
| `app_config.py` | 手动或自动 | 源码模式：手动维护 `MENU_ITEMS`；Profile 模式：build.py 按 profile 重新生成 |
| `settings.json` | 设备首次启动 / HTTP / 菜单设置 | 应用与敏感配置；**gitignore** |

### 2.2 framework/ 平台层

| 文件 | 职责 |
|------|------|
| `colors.py` | 唯一颜色定义源（CLR_BG / CLR_CARD / CLR_CYAN / ... / CLR_ORANGE） |
| `hal.py` | `init_display()` / `Buttons` 类 / `Buzzer` 类 / `LONG_PRESS_MS` 常量 |
| `wifi.py` | `connect_wifi()` 阻塞 / `check_wifi()` 状态查询 / `WiFiConnector` 非阻塞状态机 |
| `settings.py` | `load_settings()` / `get()` / `update()` / `get_wifi_configs()` / `get_api_keys()` / `get_swipe_config()` / `get_alarms()` / `reload()` |
| `http_server.py` | `start_http_server(port)` / `poll_http_server()` / `stop_http_server()` / `is_running()` / `sync_device_time()` |
| `http_server_state.py` | 服务器 socket 引用持久化（http_server 模块卸载/重载后端口不丢） |
| `qrcode.py` | 纯 MicroPython 二维码编码器（byte 模式 V1~V3、ECC M、固定 mask 0）；`get_matrix(text)` 返回矩阵供整点绘制，本机设置 HTTP 服务二维码子页使用 |
| `provision.py` | WiFi 开箱配网服务（v1.8.7）：`start_provisioning()` AP 热点+DNS 劫持+配网 HTTP / `poll_provision()` 非阻塞轮询 / `run_provision_page()` 设备端配网页（阻塞式子页）/ `boot_provision_check()` 开机引导；接口明细见 9.1 节与 WiFi配网功能文档 |
| `alarm.py` | 全局闹钟服务：`check()` 每帧调用，到点阻塞式响铃页；分钟沿匹配 + 5 分钟回看补漏 + 配置热加载 |
| `cloud.py` | 闲沐盒子云平台客户端（v1.4）：`ensure_active()` 激活换 Token（RAM only）/ `tick()` 心跳调度 / `fetch_json(source, params)` 任意数据源统一取数 / `check_bind()` 绑定确认码全屏接管 / `status()` 状态查询；指数退避 + NTP/WiFi 前置校验 |
| `audio.py` | I2S 音频输出层（v1.5.1）：`play_wav()` WAV 流式播放（边下边播/可打断/进度回调）/ `play_mp3()` MP3 流式播放（需固件 mp3dec，`mp3_supported()` 探测）/ `play_sine()` 自检音 / 数字音量移位缩放 / 正常播完收尾排空内部缓冲不砍尾；`machine.I2S` 缺失环境安全降级 |
| `news.py` | 全局整点新闻播报服务（v2.3）：`check()` 分钟沿 + 5 分钟回看 + "日-时"指纹防重；`_broadcast()` 播报接管页（取数→上稿→流播 WAV/MP3（`_resolve_audio_url`，audio_url 为 .mp3 时直连）→文字降级）；SD 挂载先落盘 `/sd/music/news_日期_时段.mp3|.wav` 再从文件播 + 今日回听；`request_play()/play_now()` 手动播报；`status()` 结果缓存 |
| `radio.py` | 网络电台服务层（v2.6）：`stream_url(code)` 流端点 URL 由台代码直拼（收听零取数）/ `stations(force)` 台单（纯内置快照 10 台，秒出）/ `play_stream(url, volume, on_progress, cancelled)` chunked 长连接直播流收听（裸 socket+ssl 手工解帧；state：ok=流结束/cancelled/limit=听众满/noent·stop=业务错/noauth=未订阅未绑定/badmp3/fail）/ `media_url(path)` 平台相对路径拼接；供 modes/radio 消费 |
| `story.py` | 听老故事服务层（v1.2）：`fetch_tags(page)`/`fetch_stories(tag, sort, page)` 目录取数（归一化 + RAM 缓存 10 分钟，条目上限 12 防碎片；stories 条目键 `htmlname`、11 本/页）/ `fetch_playlist(story_id, page)` 整本清单（story_id 传 htmlname；base_url+文件名，消毒拒路径段；不缓存，备货状态实时）/ `playlist_all(story_id, on_page)` more=true 翻页连取至全（上限 8 页）/ `play_track(url, volume, on_progress, cancelled)` 话流式播放（404→noent=服务端备货中）/ `tags_cached()/tags_cache_save()` 标签本地缓存（`/story_tags.json`，24h TTL 原子写）/ `media_url(path)`；错误码映射 40309/40302 未订阅、40001 参数错误、50401 按动作区分（均不自动重试）；供 modes/story 消费 |
| `sdcard.py` | SD 卡挂载层（v1.9）：`mount()` 独立 SPI(2) 挂载 `/sd`（20MHz 失败降 10MHz 重试，失败静默返回 False 不阻塞启动）/ `umount()` / `mounted()` / `mount_point()`；`main.py` 启动序列开机自动挂载 |
| `http_nb.py` | 非阻塞 HTTP GET 状态机（v2.2）：`Request(url, headers, timeout_ms)` → `start()/tick()/body()/close()`（DNS→连接→发送→接收分步推进，支持 Content-Length 与 chunked，全程不抛异常）；`get_json_blocking()` HTTPS 阻塞回退；stock 模式三类请求已接入 |
| `weather.py` | 心知天气 v3 抽象层：`get_weather()` / `CITIES` 城市表 / fallback 兜底 |
| `moon.py` | 月相本地计算（Conway 简化算法） |

### 2.3 三个插件目录的接口约定

| 目录 | 接口 | 实现示例 |
|------|------|---------|
| `boot_animations/` | `play(display, buzzer)` | `matrix.py` |
| `menus/` | `run_menu(display, buttons, buzzer) -> mode_id_str` | `list.py` / `carousel.py` |
| `modes/` | 继承 `BaseMode`，实现 `enter()` / `loop()` / `exit()` | `clock.py` / `swipe.py` / ... |

新增插件只需：
1. 在对应目录新建 `.py`
2. 在 `app_config.py`（或 `profiles/*.json`）追加条目
3. 在 `modes/registry.py`（或 `profiles/*.json`）追加映射
4. 运行 `python tools/test.py` 验证

## 3. devices/ 设备档案

```
devices/
├── __init__.py
└── esp32s3_n8r8.py           # ESP32-S3 N16R8（当前主目标）
```

每份档案必须定义以下字段（`tests/test_config.py` 强制校验）：

```python
CHIP, BOARD_NAME
TFT_SCL, TFT_SDA, TFT_RES, TFT_DC, TFT_CS, TFT_BLK
BTN_A, BTN_B, BTN_C, BUZZER_PIN
W, H, ROTATION, BUFFER_SIZE
HAS_BLE, HAS_PSRAM, MAX_FONT_SIZE
```

新增设备：
1. 复制 `esp32s3_n8r8.py` 为 `devices/<新设备>.py`
2. 修改引脚、屏幕参数、BOARD_NAME
3. `python tools/build.py --profile full --device <新设备>` 验证

## 4. profiles/ 功能组合配置

```
profiles/
├── full.json                 # 全功能版（13 个功能）
├── minimal.json              # 最小版（网络时钟 + 设置）
└── clock_only.json           # 仅网络时钟版
```

每份 Profile 描述一次完整的功能组合：

```json
{
  "name": "全功能版",
  "description": "XianMuBox 完整功能集",
  "device": "esp32s3_n8r8",
  "features": [
    {
      "id": "net_clock",
      "name": "网络时钟",
      "color": "CLR_CYAN",
      "icon": "/icons/clock.png",
      "module": "modes.net_clock",
      "class": "NetClockMode"
    },
    ...
  ],
  "boot_animation": "matrix",
  "menu_style": "list",
  "wifi": true
}
```

build.py 根据 `features` 数组自动生成：
- `app_config.py` 的 `MENU_ITEMS`
- `modes/registry.py` 的 `_MODULE_MAP`
