# 听老故事模式（StoryMode）功能文档

> 模块路径：`src/modes/story.py`（`StoryMode`）；服务层 `src/framework/story.py`
> 关联资源：`font/hanzi_24`（标题/书名/状态文案）、`font/vga1_8x8`（页码/数量/按键提示）、`/icons/news_spk_0~3.raw`（播放页喇叭帧动画，与新闻播报/网络电台共用素材）、`/icons/story.png`（菜单图标，48×48，由 `tools/gen_story_icon.py` 生成）

> 构建绑定：`profiles/full.json → {"id": "story", "module": "modes.story", "class": "StoryMode"}`
> 最近更新：2026-09-19（v1.3 标签本地缓存：`/story_tags.json` 秒进模式、24h TTL 静默刷新、失败静默沿用；v1.2 翻页交互改版：批末尾绿色「拉取新标签/拉取新故事」菜单行；v1.1 适配平台契约改版 htmlname/11 本页/001.mp3；v1.0 首版接入）

## 一、功能概述

收听闲沐盒子数据服务平台 `comic_audio` 连环画语音源（闲沐连环画 wwzu.com 内容，官方手册 2.9）：平台把「语音完整」的小人书按页合成 MP3，设备按「标签 → 标签下故事 → 整本播放清单」三级浏览、整本顺序收听。

1. **三级浏览模型**：`tags`（10 个/批，按收录量降序）→ `stories`（标签下 11 本/批，仅收录语音完整的书，条目键为 `htmlname`——v1.1 契约改版后无数字 id）→ `playlist`（整本播放清单，一次返回全部有音页）。列表翻页手动化（v1.2）：每批末尾追加绿色「拉取新标签/拉取新故事」菜单行，光标停其上按 B 才拉取下一批，A 键仅在条目+菜单行内循环、永不触发网络请求
2. **顺序流式播放**：清单 `base_url`（站内相对路径）+ 文件名拼接完整地址（`media_url`，`/media` 无鉴权静态中转），urequests 直连边下边播（`audio.play_mp3`）；文件名为页号顺序名（`001.mp3…`，v1.1 契约改版后**无梗概前置条**，源站真实文件名不再下发）；服务端收到清单请求已备货前 3 条（起播零等待），话间衔接约 2~4s（1 次连接）——**单线程不做真双缓冲**（无法边播边下），v2 可评估 `_thread` 预取
3. **同书续播记忆**：播放中记录 `settings.story` 的 `last_tag/last_story/last_track`（播完一话即写，整本播完归零）；标签页与故事页光标自动定位上次位置，同书再按 B 从上次听到的话继续
4. **错误分级退避**：清单/话 404 = 服务端仍在备货 → 1s 起连败翻倍封顶 60s 短退避；网络类失败 15s×2 → 60s 起指数翻倍上限 30 分钟；未订阅（40309/40302，唯一开通途径 = 平台门户邀请码兑换）/参数错误（40001）不自动重试；50401 按动作区分——目录请求（tags/stories）显「内容库不可达」（平台上游连环画库故障，与音频无关），清单请求显「暂无音频」（故事不存在/无音频）
5. **固件依赖**：需含 `mp3dec` 模块的固件（mp129-romfont-mp3dec 起），无解码器进入模式即提示「请更新固件」
6. **标签本地缓存（v1.3）**：`/story_tags.json`（闪存根）存第 1 批+total（约 600B，原子写防掉电，带 ver/saved_at）；进入命中缓存即秒出列表（**无等待页**，光标定位照旧），24h TTL 内本批不发请求；陈旧由 loop 静默刷新（成功且数据有变化才替换+落盘+重绘，失败静默沿用缓存不出错误页）；损坏/版本不符自动弃用走在线取数。弱网/离线时模式始终可用

## 二、页面结构与导航

```
标签列表页(默认) --B--> 故事列表页 --B--> 播放页(阻塞接管)
故事列表页 --C--> 返回标签列表页
播放页 --B--> 返回故事列表页
播放页 --A--> 下一话(跳过, 留在播放页)
播放页整本播完 --A--> 重取清单从头再听
列表翻页(v1.2): A 仅在「已取条目+翻页菜单行」内循环不取数;
                光标停菜单行按 B → 拉取下一批 (取尽=回到首页)
进入(v1.3): 本地缓存命中 → 秒出标签列表 (无等待页);
            无缓存 → 标签拉取等待页
C短按: 标签列表页 → 退出模式
固件提示页(无 mp3dec 时, 任意键 → 退出模式)
目录/清单拉取等待页(阻塞拉取时, 整页绘制清除载入图)
```

## 五、后台服务 / 业务规则

模式为按需收听型，无后台定时器（BaseMode.run 每帧的全局闹钟/新闻/云端检查在播放页阻塞接管期间暂停，与网络电台惯例一致）。话循环状态机（`_listen`）规则：

| 规则 | 行为 |
|------|------|
| 分页拉取 | 列表翻页手动化（v1.2）：每批末尾绿色「拉取新标签/拉取新故事」菜单行，光标停其上按 B 才拉下一批（成功后光标落新批首条；失败原地红字约 2 秒、列表不破坏，可再按 B 重试）；批取尽菜单行变「回到首页」（B=光标回首条不取数）；A 键永不触发网络请求 |
| 标签缓存 | `/story_tags.json`（闪存根，v1.3）：存第 1 批+total（约 600B，原子写，ver/saved_at），进入命中直绘无等待页，<24h 免请求，陈旧静默刷新（成功且有变化才替换+落盘+重绘，失败静默沿用），损坏/版本不符弃用；第 2 批以后仍实时拉取 | 无/损坏缓存 = 走在线取数，行为同 v1.2 前 |
| 清单获取 | 播放页 B 进入先 `playlist_all` 连取整本清单（128 条/页，`more=true` 自动翻页至全，上限 8 页保护）；不缓存（备货状态实时变化，每次进入重取） |
| 话循环 | 按清单顺序逐话 `play_track`（urequests 直连 `base_url + 文件名` 边下边播）；播完一话写入续播位并自动进入下一话；话间显示「下一话」后即连 |
| 文件名页码 | 文件名为页号顺序名（`001.mp3` → 第 1 页；v1.1 契约改版后无梗概前置条，从第 1 页顺序播）；无音页（内容提要/封底）平台不下发，设备无需跳过；条目消毒拒绝带路径/相对段的文件名 |
| 备货中 404 | 清单已列但该条未落盘（长书快进/刚上架场景）→ 状态「备货中」，1s 起连败翻倍封顶 60s 短退避重试同一话（不紧刷不轻弃） |
| 网络退避 | 网络失败/云服务异常/播放中断/解码异常：第 1~2 档等 15s，之后 60/120/240/... 秒翻倍上限 30 分钟（`_net_wait_sec`） |
| 未订阅 | 40309（自助开通已关闭）/40302：显「未订阅」+ 引导行「网页兑换邀请码」，不自动重试恒候按键——该付费源唯一开通途径 = 平台门户邀请码兑换（官方手册 2.9/3.10），设备端不做兑换 |
| 其他业务错 | 40001 参数错误恒候按键；50401 按动作区分文案——目录请求（tags/stories）=「内容库不可达」（平台上游库故障），清单请求=「暂无音频」（故事不存在/无音频），均不自动重试恒候按键；所有非 0 业务码同时在串口打印 `[STORY] platform code: N msg: <平台原始msg>`（真机排障看 REPL） |
| 跳话 | 播放页 A：打断当前话 → 下一话（续播位随之推进） |
| 续播 | 每话开始/播完写 `settings.story`（`last_tag/last_story/last_track`）；同书再进从 `last_track` 继续（0 < track < 总话数才生效）；整本播完归零，完本页 A = 重取清单从头再听 |
| 音量 | `settings.story.volume`（0-100），异常回退 80 |

## 六、性能与资源

- 服务层 `framework/story.py` 惰性 import（urequests/ujson/settings/cloud 均函数内导入）；目录类结果（tags/stories，归一化后）RAM 缓存 10 分钟、条目上限 12 条防碎片，缓存过期或失败即时重取；playlist 不缓存
- 播放走 `audio.play_mp3` 滑窗（16KB 补数窗 + 4.6KB 解码输出），无整话进 RAM；播放页动态 UI 由 `on_progress` 每秒驱动（喇叭帧变化才 blit）
- 模式退出 `exit()` 清空标签/书单/字体/帧缓存并 `gc.collect()`；模式模块由 main.py 统一卸载
- 喇叭帧 raw 首次使用读入常驻缓存（4 帧共 80KB），缺失时动画区纯黑安全降级

## 八、状态与已知问题

- **每页尾句被切已修（audio v1.5.1，2026-09-19）**：真机首曝"每页最后一点没播完就切下一话"——根因在框架音频层：`I2S.write()` 返回只代表数据已拷入 64KB 前置缓冲（常驻约 0.3~0.7s 尾音），播放结束立即 `deinit` 把尾音砍掉；已在 `play_wav/play_mp3` 正常播完路径加排空等待（打断仍即时）。部署新版 `framework/audio.py` 生效，模式层无需改动
- **2026-09-19 平台契约改版已适配（v1.1）**：stories 不再返回数字 id 改 `htmlname`（11 本/页）；playlist/pages 的 `story_id` 传 htmlname；清单无梗概前置条，文件名为页号顺序名 `001.mp3…`；按旧数字 id 请求平台将返回 50401（故事不存在）。设备端 `settings.story.last_story` 同步 int→str（存量数字值转字符串后无害失配，续播位自动回到从头，无需迁移）
- **需订阅**：`comic_audio` 为付费源，设备需已在平台兑换邀请码开通（自助 enable/config 返回 40309），否则取数 40309/40302（页面显「未订阅 + 网页兑换邀请码」引导）
