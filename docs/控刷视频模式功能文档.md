> 模块路径：`src/modes/swipe.py`（`SwipeMode`）
> 关联资源：`font/hz_24x24.mpy`（中文）、`vga1_8x16`（ASCII 信息行）、`bluetooth`（ESP32 BLE，真机可用）

## 一、功能概述

基于 **BLE HID 触摸屏协议** 的自动滑动控制器：ESP32 模拟触摸屏设备，驱动已连接手机自动滑动，适用于自动刷短视频、翻页等场景。

1. **真实触摸屏协议**：Digitizer HID 报告，非键盘模拟，兼容性更强；
2. **多机切换**：BLE 协议栈支持最多 5 台手机同时连接，A 长按切换活跃设备（全项目唯一保留的长按功能）；
3. **自动滑动**：随机间隔自动执行滑动，间隔可配置；
4. **参数可调**：偏移比例、步数、延迟按设备独立记忆，适配不同手机；
5. **远程调参**：HTTP 配置页 `/api/config` 可改任意 `swipe` 参数。

## 二、页面结构与导航

单页应用，含"等待连接 / 运行 / 停止 / 错误"四个状态：

```
进入模式 → BLE 初始化
  ├─ 失败 → 错误页(等待 C 退出)
  └─ 成功 → 等待连接(点点动画) --手机连上--> 停止态 --A短按--> 运行态 --A短按--> 停止态
C短按(非运行): 保存配置并退出
```

## 三、按键表（全模块一张表）

| 状态 | A 短按 | A 长按 | B 短按 | C 短按 |
|------|--------|--------|--------|--------|
| 停止态（BLE 已连接） | 启动自动滑动 | 切换活跃设备（需 ≥2 台连接） | 切换滑动模式（循环，并应用该模式参数） | 保存配置并退出 |
| 运行态 | 停止自动滑动 | 禁用 | 禁用 | 禁用（先 A 停止再退出） |
| 等待连接态 | — | — | — | 保存并退出 |
| 错误页 | — | — | — | 退出 |

> **按键规范差异说明**：本模式为全项目唯一保留长按功能的模式（《框架架构设计文档》2.4 记载的例外项）——A 长按 = 切换 BLE 设备，仅非运行态可用。屏幕底部另有"停止 / 模式 / 退出"三按钮区，与实体按键语义一一对应，按钮有按下/禁用视觉状态。

## 五、运行规则

### 5.1 自动滑动

- 启动后按 `interval_min ~ interval_max` 秒的**随机间隔**循环滑动（每轮开始时重新生成间隔）；
- 启动瞬间立即执行一次滑动；滑动时蜂鸣反馈（上滑 1000Hz / 下滑 700Hz）。

### 5.2 多机切换

- ESP32 作为 BLE 外设（广播名 `esp32-xm`）持续广播，多台手机作为中心设备同时连入（最多 5 台）；
- 新设备连接自动注册命名（`Phone1`、`Phone2`…，有历史记录则沿用旧名）；连接高音 1200Hz、断开低音 400Hz；
- 断开后自动切到剩余设备并继续广播；全部断开回到等待连接态；
- A 长按切换活跃设备时，同步应用该设备记忆的参数（分辨率、滑动参数）并刷新 UI。

### 5.3 滑动模式列表

| 索引 | 名称 | 方向 | 状态 |
|------|------|------|------|
| 0 | 刷新视频-上滑 | up | 已实现 |
| 1 | 刷新视频-下滑 | down | 已实现 |
| 2 | 看书-左滑 | left | 预留扩展 |
| 3 | 看书-右滑 | right | 预留扩展 |

### 5.4 BLE HID 协议细节

- **报告描述符**：Digitizer（触摸屏）Usage Page 0x0D，支持 Contact / Tip Switch / 16 位 X-Y 坐标（0~32767）；
- **坐标映射**：`hid_x = pixel_x * 32767 / screen_w`，`hid_y = pixel_y * 32767 / screen_h`；
- **滑动轨迹**（以上滑为例）：按下 (cy+off/2) → 5 步渐进到 (cy-off/2) → 定格（tip=0）→ 释放，共 7 个报告；
- **GATT**：HID Service `0x1812`，Report `0x2A4D`（READ+NOTIFY），Output Report `0x2A4E`，CCCD `0x2902`。

## 六、性能与资源

- `http_server`（poll_http_server）延迟到首次调用才导入，避免加载本模块时连带编译大模块（后续走 `sys.modules` 缓存）；
- 进入模式后关闭 WiFi STA 减少蓝牙干扰（`network`）；
- 运行态与等待动画均为局部重绘（BLE 行、按钮、信息行），无整屏闪烁；
- `exit()` 保存配置 + HIDTouch `deinit()` 释放 BLE 资源。

### 类架构

```
SwipeConfig   配置管理器: load/save/get_swipe_offset/apply_mode_config/
              apply_device_config/register_or_update_device
HIDTouch      BLE HID 驱动: _init/_irq(多设备)/is_connected/conn_count/
              get_active_name/switch_device/deinit/send_touch/swipe_up/swipe_down
SwipeMode     主模式(BaseMode): enter/loop/exit + 绘制与状态检测方法
```

### 参数调优指南

| 参数 | 增大效果 | 减小效果 |
|------|----------|----------|
| `swipe_offset_ratio` | 滑动距离变短 | 滑动距离变长 |
| `swipe_steps` | 更平滑、更慢 | 更快、更粗糙 |
| `swipe_delay_ms` | 更慢 | 更快 |

| 常见问题 | 解决方案 |
|----------|----------|
| 手机无法触发滑动 | 减小 `swipe_offset_ratio`（如 4 或 3） |
| 滑动太慢 | 减小 `swipe_steps`（如 3）或 `swipe_delay_ms`（如 10） |
| 滑动不稳定 | 增大 `swipe_steps`（如 8~10） |
| 高分屏滑动距离不够 | 减小 `swipe_offset_ratio` + 增大 `swipe_steps` |

预设参考：720×1280 与 1080×1920 → ratio 6 / steps 5 / delay 20；1080×2340 与 1080×2400 → 5/6/18；1440×2560 与 1440×3200 → 4/8/15。

三种调参方式：① HTTP 配置页 Swipe 区块（推荐，实时校验）；② 直接编辑 `settings.json`（注意合法范围）；③ 设备端按钮（仅部分参数）。

## 八、状态与已知问题

- 运行态下 C 键被禁用，需先 A 短按停止再退出（防止滑动中途状态丢失）；
- "看书-左滑/右滑"为预留扩展，`send_touch` 轨迹尚未实现对应手势。
