# 项目仪表 API 接入规范

> 版本：v2.0 | 适用模块：`src/modes/dashboard.py`

---

## 一、概述

项目仪表模式是一个多站点数据看板，通过 HTTP GET 请求拉取站点 API 的实时数据，在 240×240 屏幕上分页展示。用户只需配置 API 地址和密钥，设备会自动拉取并渲染。

---

## 二、配置方式

在 `src/settings.json` 的 `project.own_sites` 数组中添加站点配置项：

```json
{
  "project": {
    "own_sites": [
      {
        "name": "Wwzu.Com",
        "api": "https://www.wwzu.com/api/device/stats",
        "key": "your-api-key-here"
      },
      {
        "name": "MooView.Cn",
        "api": "http://www.mooview.cn/api/?action=stats",
        "key": "your-api-key-here"
      }
    ]
  }
}
```

| 字段 | 必填 | 说明 |
|------|:--:|------|
| `name` | 是 | 站点名称，显示在标题栏，不可为 `stock`（该名称被股票模式占用） |
| `api` | 是 | 完整的 API 地址，支持 `http` / `https` |
| `key` | 否 | API 密钥，为空时不携带认证参数 |

---

## 三、请求规范

### 3.1 请求方式

```
GET <api>?api_key=<key>
```

- 设备自动拼接 `api_key` 参数
- 如果 API 地址本身已包含查询参数（含 `?`），则用 `&` 拼接
- 超时时间：10 秒

**示例**：配置 `"api": "https://example.com/stats", "key": "abc123"`  
实际请求：`GET https://example.com/stats?api_key=abc123`

### 3.2 请求头

- `User-Agent`: MicroPython 默认
- 无需额外设置 Content-Type（GET 请求无 Body）

## 四、响应规范

### 4.1 结构 A（推荐 — 嵌套结构）

```json
{
  "success": true,
  "data": {
    "日期": "2026-06-28",
    "访问": 1280,
    "注册": 35,
    "订单": 12,
    "付款": 998.50
  }
}
```

- `success` 为 `true` 时，取 `data` 内的所有键值对
- `data` 必须是 JSON 对象

### 4.2 结构 B（平铺结构）

```json
{
  "访问": 1280,
  "注册": 35,
  "付款": 998.50,
  "success": true,
  "message": "ok"
}
```

- 设备自动剔除以下元字段：`success`、`error_code`、`message`
- 剩余所有键值对作为展示数据

### 4.3 字段命名

**推荐直接使用中文键名**，设备将原样显示。下划线 `_` 会自动替换为空格。

| 字段名 | 显示效果 |
|--------|----------|
| `访问` | 访问 |
| `paid_orders` | paid orders |
| `页面浏览量` | 页面浏览量 |

---

## 五、显示规则

### 5.1 字段展示

- 每个站点最多显示 **5 个字段**，超出部分不显示
- 所有字段统一使用 24×24 大字体，行高 30px
- 字段名左对齐，字段值右对齐，中间用冒号分隔

### 5.2 日期行

如果返回数据中包含 `date` 键，其值将单独显示在底部日期行（灰色小字，居中），**不会出现在上方字段列表中**。

### 5.3 特殊键名 `date`

`date` 字段会被自动跳过，统一在底部日期行渲染。如果你想在字段列表中显示日期，请使用其他键名如 `日期`。

## 六、操作说明

| 按键 | 功能 |
|------|------|
| A 短按 | 下一张卡片（循环） |
| B 短按 | 立即刷新全部数据 |
| C 短按 | 退出返回主菜单 |
| 自动 | 每 60 秒自动刷新并切换到下一张卡片 |

## 七、完整示例

### 服务端返回（PHP）

```php
<?php
header('Content-Type: application/json');

$data = [
    'success' => true,
    'data'    => [
        'date'       => date('Y-m-d'),
        '访问'       => 1280,
        '注册'       => 35,
        '订单'       => 12,
        '付款'       => 998.50,
        '对话'       => 89,
    ]
];

echo json_encode($data);
```

### 设备端配置

```json
{
  "project": {
    "own_sites": [
      {
        "name": "我的站点",
        "api": "https://mysite.com/api/stats",
        "key": "abc123"
      }
    ]
  }
}
```

## 八、常见问题

**Q: API 返回了 6 个字段，只显示了 5 个？**  
A: 这是设计限制。最多显示 5 个非 `date` 字段以确保屏幕可读性。

**Q: 日期行不显示？**  
A: 请确保返回数据中包含 `date` 键（英文小写），值非空。

**Q: 如何远程修改配置？**  
A: 设备启动后会开启 HTTP Server（默认端口 80），可通过 `POST /api/config` 修改 `settings.json`。

**Q: 支持 HTTPS 吗？**  
A: 支持，但取决于 MicroPython 固件是否编译了 SSL 模块。
