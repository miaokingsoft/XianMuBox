# 模式功能文档模板（新增功能插件时照此填写）

> 本模板定义 XianMuBox 所有功能模式说明文档的统一骨架。
> 新增一个模式（`src/modes/xxx.py`）时，复制本文件为 `doc/<功能名>模式功能文档.md`，
> 按各节"填写说明"替换占位内容后删除说明文字。
> 填写原则：**以源码为唯一事实源**——按键语义、数据来源、布局坐标逐项对照代码核实，不凭记忆写。

---

# <功能名>模式（<EnglishModeName>）功能文档

> 填写说明：H1 = 中文功能名 + 英文模式名，与菜单项名称、`BaseMode` 子类名对应。

> 模块路径：`src/modes/xxx.py`（`XxxMode`）
> 关联资源：模式依赖的字体/图标/子包（如 `font/hz_24x24.mpy`、`morse/` 包）
> 配置文件：`settings.json` 中被读取的节点（无则写"无"）
> 构建绑定：`profiles/*.json → {"id": "xxx", "module": "modes.xxx", "class": "XxxMode"}`
> 最近更新：YYYY-MM-DD（本次文档改版摘要，一句话）
