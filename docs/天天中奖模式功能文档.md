## 一、功能概述

双色球 / 大乐透 **机选 + 当期对奖** 模式：

1. **进模式零联网**：直接读取本地 `/lottery.json` 渲染彩种菜单；确认进入某彩种后才自动联网拉取最新开奖；
2. **两彩种独立票池**：双色球与大乐透各自维护当期票池（恒为最新 3 组），切换彩种只是换视图，不清票；
3. **开奖号码页为彩种默认页**：进入即自动拉取最新开奖显示（云优先，回落第三方源），「兑奖」按钮手动核对当期票池并弹出结果提示，避免未确认的自动对奖；
4. **机选一次 3 组、替换式保存**：机选画面本地随机 3 组候选同屏（16px 数字），「保存」时才联网确定期号，**当期票池整体替换为本次 3 组**（不是追加）；
5. **进度反馈**：云路径显示「平台取数中」静态提示；回落路径保留流式进度条（分块回调，按 Content-Length 算百分比）。

## 二、页面结构与导航

```
页0 彩种菜单 --B(确认)--> 页1 开奖号码页 --B(机选)--> 页2 机选画面
     ^  ^                     |  ^                       |
     |  +-----C(回菜单)-------+  +------C(回菜单,丢弃候选)-+
     +----------- 选中「退出」项 = 退出整个模式 -----------+
```

- **页1 / 页2 的 C 短按都是回彩种菜单**（模式内闭环），退出整个模式只走页0 菜单的「退出」项；
- 菜单页遵循框架**列表类**按键规范（A=上移 / B=确认 / C=下移），与主菜单一致；
- **扩展性**：新增彩种只需扩展 `_GAMES` 配置与 `_GAME_ORDER`（及 `judge_prize` 奖级分支），菜单与页面自动生成。

## 三、按键表

| 页面 | A | B | C |
|------|---|---|---|
| 页0 彩种菜单（列表类） | 选中项上移 | 确认（进入开奖号码页，自动联网拉开奖；"退出"项=退出模式） | 选中项下移 |
| 页1 开奖号码页 | 兑奖（核对当期票池 + 弹结果提示） | 进入机选画面 | 回彩种菜单 |
| 页2 机选画面 | 保存（联网定期号，3 注入池，回开奖号码页） | 再选（重新随机 3 组） | 回彩种菜单（丢弃候选） |

## 四、各页布局（240×240）

> 号码区身份角标：**开奖 = 红色角标**（`_draw_tag`，24 点阵字色块）；机选候选用红/蓝 16px 数字文本，与开奖大球明确区分。

### 4.0 页0 彩种菜单

- 顶部红色标题栏：`天天中奖`（左，白）+ `选彩种`（右，金）；
- iOS 卡片列表（风格对齐主菜单，`_draw_menu_row`）：每彩种一行 = 彩种名（左，24 点阵）+ 持票状态（右）+ 第二行开奖日期时间（ASCII）；末项为 `退出`；
  - **持票状态**：`已选N注` **绿色**（CLR_GREEN）/ `无机选` 灰；
  - **开奖日提醒**：当天（`time.localtime()[6]`）命中该彩种开奖日（双色球周二/四/日、大乐透周一/三/六）时，时间行变**红色**（优先级最高）；非开奖日持票 = 青、无票 = 灰；
- 选中行 = 卡片底色 + 白描边 + 白字（同主菜单），支持滚动（同屏 3 行，`MENU_VIS`）。

### 4.1 页1 开奖号码页（彩种默认页）

- 顶部红色标题栏：`开奖`（左，白）+ 当前彩种名（右，金）——注意左栏不再是「天天中奖」；
- **进入即自动联网拉取最新开奖**（`_auto_fetch`，云优先 + 回落，进度提示同机选）；拉取只刷新显示**不自动对奖**，核对动作留给「兑奖」；
- 开奖区（整体上移布局）：**开奖期号左对齐（白）+ 开奖日期右对齐（青 ASCII）同一行（y=44）**，下接开奖球一行（y=73，r=15、24 点阵、前区红 / 后区蓝）；
- **拉取失败回退**：有上次对奖缓存（`last_result`）时显示缓存开奖——期号/日期/球整体灰化（CLR_DIM）+ 提示「上次开奖 请联网刷新」；无缓存则显示「网络读取失败 / 请联网后刷新」；
- 状态行（y=106）：`{机选期号} - 未开奖`（琥珀，指当期持票期号）/ `{期号} - 已兑奖`（金，取 `last_result.period`）/ `当期无已选`（灰）；
- 号码区（y≥136，细分隔线之下）：
  - **有票** → 票池 3 组机选号码，每注一行 16px 数字（前区红 / 后区蓝，号码间仅 2px 间隔、不加分隔符，与机选画面同款式）；
  - **已兑奖** → 逐注明细（ASCII 最多 5 行：每注号码 + 命中数 + 奖级 `#6`，中奖行金色）；
- 底部按钮：`兑奖 | 机选 | 退出`（A/B/C 顺序，左钮 = A）。

### 4.2 页2 机选画面

- 顶部标题栏同页1；期号行：持票期 `第×××××××期`（白）/ 无持票期 `选3注`；
- 候选提示行（青）：`已选M注 新3注`（M=票池现有注数，M=0 时仅 `新3注`）；
- **3 组候选号码**：每注一行，**16px 数字文本**（`vga1_16x16`，缺失回退 8x8 防崩），前区红色 / 后区蓝色，号码间仅 2px 间隔、不加分隔符（与开奖页票池区同款式；`PICK_Y0=108`，行距 28）；
- **出号动画**：进入与再选时号码区滚动随机号码 6 帧后定格（`_roll_anim3`，页框架保持可见）；
- 底部按钮：`保存 | 再选 | 退出`（A/B/C 顺序）；
- **保存**（`_pick_save`）：需联网（无网提示「请联网后保存」留在本页）→ 拉最新开奖（云优先/回落）→ 旧持票期已开奖先对奖清池 → 期号推进（平台 `sale_period` 优先）→ **当期票池替换为本次 3 组** → 提示 `已选3注` → 回开奖号码页；
- **再选**：本地重新随机 3 组（零延迟）；**退出**：丢弃候选回彩种菜单。

## 五、机选与对奖规则

| 彩种 | 号码构成 | 开奖日 | 开奖时间 | 云平台源代码 |
|------|---------|--------|---------|-------------|
| 双色球 ssq | 红球 6/33（升序）+ 蓝球 1/16 | 周二/四/日 | 21:15 | `lottery_ssq` |
| 大乐透 dlt | 前区 5/35 + 后区 2/12（升序） | 周一/三/六 | 21:25 | `lottery_dlt` |

- **机选**：随机不重复抽样，一次生成 **3 组**候选；「保存」时才联网确定期号（显示候选阶段零联网），**替换式写入**——当期票池整体替换为本次 3 组（新号码替换老号码，`MAX_TICKETS = 3`）；云路径下新持票期**优先采用平台 `sale_period`（在售期号，官方权威）**，平台未提供时按 `next_period_info()` 推算；
- **兑奖**：手动触发（A 键）。拉最新开奖（进页已拉到则直接复用）→ 持票期未开奖提示「等待开奖」→ 已开奖则逐注判定奖级写入 `last_result` 并**清空票池**，弹出结果提示（`中N注 X元` / `命中浮动奖` / `未中奖`，中奖播报旋律）；中奖金额见 `judge_prize`：
  - 双色球：一等（红6蓝1，浮动）/ 二等（红6，浮动）/ 三等 3000 / 四等 200 / 五等 10 / 六等（蓝球命中）5；
  - 大乐透：一等（5+2，浮动）/ 二等（5+1，浮动）/ 三等 10000 / 四等 3000 / 五等 300 / 六等 200 / 七等 100 / 八等 15 / 九等（3+0、2+1 或 后区2命中前区≤1）5；
  - 金额 `-1` = 浮动奖金，`0` = 未中奖。

## 六、数据与存储

| 数据 | 来源 | 说明 |
|------|------|------|
| 开奖数据（主源） | 云平台 `GET /api/v1/data/lottery_ssq\|lottery_dlt` | 经 `framework/cloud.py` 统一取数（需在设备 Web「云服务」页配置激活密钥、平台侧登记 SN 并订阅彩种源）；payload 适配为统一结构（期号规范为本地约定长度：双色球 7 位 / 大乐透 5 位），**仅最新一期**；`sale_period` 非空时作为新一期期号 |
| 开奖数据（回落） | `data.17500.cn/*_asc.txt` | 云未配置 / 未激活 / 40101 未绑定 / 40302 未订阅 / 42901 限流 / 网络失败时**自动静默回落**；行格式：期号 日期 红×6 蓝（或前区×5 后区×2）+ 统计列；流式分块读 socket，只留尾部 12 期 |
| 票池 | `/lottery.json` | 每彩种独立 `{period, expect_date, tickets, last_result}`；票池恒为最新 3 组（替换式保存）；临时文件 + rename 原子落盘 |
| RNG 种子 | `_seed_rng()` | 机选时用硬件熵/时间播种，避免每次机选相同序列 |

- **触发时机**：开奖号码页进入时与「兑奖」「保存」均会拉取开奖数据（云优先回落 17500）；页0 菜单与机选画面显示阶段零联网；
- **对奖范围说明**：云路径仅能取到最新一期，持票期早于最新期时按既有兜底逻辑以最新一期对奖（与 17500 尾部窗口外场景一致）；正常使用节奏（当期购买、开奖后兑奖）完全覆盖；
- **来源留痕**：云路径的 `source_name` 免责文案存入 `last_result.source` 落盘（页面布局紧凑不上屏）。
