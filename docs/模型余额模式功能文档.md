# 模型余额模式（AI Balance）功能文档

> 模块路径：`src/modes/ai_balance.py`（`AIBalanceMode`）
> 关联资源：`font/sy_32x32.mpy`（服务商名/余额大字，首次绘制才加载）、`font/hz_24x24.mpy`（中文）
> 配置文件：`settings.json → api_keys`（多服务商多 Key，v1.2 schema）、`settings.json → api_keys_hidden`（停用显示的服务商）
> 构建绑定：`profiles/full.json → {"id": "ai_balance", "module": "modes.ai_balance", "class": "AIBalanceMode"}`
> 最近更新：2026-09-01（按统一模板重写，内容对照源码核实）

---

## 一、功能概述

AI 服务商 API 余额监控：每个（服务商，Key）组合一张卡片，实时查询余额并多卡轮播。

1. **多 Key 多卡**：`api_keys` 中每个服务商的所有有效 Key 展开为独立卡片（`ai_token` 单值项跳过）；`api_keys_hidden` 列表中的服务商整体不显示；
2. **免重启生效**：每次 `enter()` 重新读取 settings.json，Web 端编辑 Key 后无需重启；
3. **余额按数值着色**：≥10 元青色（充足）/ 1~10 元琥珀（警示）/ <1 元或查询失败红色（危险）；
4. **双自动**：60s 自动轮播 + 5 分钟全卡轮刷新；
5. **Web 联动**：HTTP 服务提供 `GET /api/balance`（内部调本模块 `_fetch_balances_now()`），Web 配置页可直接查看各 Key 实时余额。

## 二、页面结构与导航

单页多卡片视图（无子页面）：

```
空态(无Key) --配置Key后--> 卡片视图(逐卡loading → 常规轮播)
C短按: 任何状态(含loading/刷新中) → 退出模式
```

## 三、按键表（全模块一张表）

| 页面/状态 | A | B | C |
|-----------|---|---|---|
| 卡片视图 | 翻下一张卡（循环，250ms 防抖） | 立即刷新当前卡余额 | 退出模式 |
| 首次 loading（逐卡拉取） | 不响应 | 不响应 | 中断并退出 |
| 刷新中（进度条） | 不响应 | 不响应 | 中断并退出 |
| 空态（未配置 Key） | 不响应 | 不响应 | 退出模式 |

- 无长按/双击手势。切卡与轮播切换时有蜂鸣反馈：余额 ≥1 元 900Hz，<1 元或失败 1500Hz（低余额高音提醒）。

## 四、各页布局（240×240）

### 4.1 卡片视图

| 区域 | 内容 |
|------|------|
| 顶部 y0-50 | 柠檬绿标题栏（模式标识） |
| y80 一带 | 服务商名大字（`sy_32x32`） |
| y124 一带 | 模糊化 API Key 副标题（8x8 柠檬绿，仅保留可辨识尾段） |
| y160 一带 | 大号余额（`sy_32x32`，按余额三档配色） |
| y209 一带 | 刷新进度条（刷新时显示） |
| y226 一带 | 分页方块（当前卡位置指示） |

### 4.2 首次 loading 态

逐卡拉取（每帧一张），底部进度条显示真实进度；全部拉完后进入常规视图。

### 4.3 空态

"未配置 Key"提示 + "请在 HTTP 页配置"指引（Web 配置页 → API Key 页签）。

## 五、后台服务

| 服务 | 行为 |
|------|------|
| 60s 自动轮播 | 非阻塞计时切换下一张卡，切卡蜂鸣（900/1500Hz 按余额）；空态不响应 |
| 5 分钟全卡轮刷新 | 到点逐张拉取全部卡片（进度条显示步进进度），刷完自动切到下一张；B 触发的单卡刷新完成后原地不动 |

## 六、性能与资源

- `sy_32x32` 大字体（约 7KB）延迟到首次绘制才 import（`_get_num_font()`），避免与蓝牙等模块残留挤占内存导致 OOM；
- HTTP 请求主动 close response 防连接泄漏；逐卡拉取、每张之间 `gc.collect()`；
- B 刷新采用"先蜂鸣 + 进度条扫入动画，再进入 HTTP 阻塞"的顺序，阻塞期间进度条保持显示，避免用户以为死机。

## 七、数据依赖

| 数据 | 来源 | 缺失表现 |
|------|------|----------|
| Key 列表 | `settings.json → api_keys`（provider → `[{label, key}, ...]`，跳过 `ai_token` 与 `api_keys_hidden` 中的服务商） | 空态页 |
| DeepSeek 余额 | `GET https://api.deepseek.com/user/balance` → `balance_infos[0].total_balance` | 卡片余额 `--`（红） |
| SiliconFlow 余额 | `GET https://api.siliconflow.com/v1/user/info` → `data.totalBalance`/`data.balance`。**原 `/user/info` 于 2026-08-14 停服返回 410，域名已 .cn→.com，替代接口待官方发布** | 卡片显示琥珀色"停服待恢复" |
| Kimi(Moonshot) 余额 | `GET https://api.moonshot.cn/v1/users/me/balance` → `data.available_balance` | 卡片余额 `--`（红） |
| Zhipu 余额 | 暂无公开余额接口 | 卡片显示"接口未配置"提示 |

> 各适配器集中在模块的 `_BALANCE_ADAPTERS` 表，厂商接口字段变化时只需改该表对应条目。
