## 二、按键统一规范速查

> 全文见 [框架架构设计文档](框架架构设计文档.md) 2.4 节（2026-08-30 确立，**短按为主、不用长按**）。

| 页面类型 | A 短按 | B 短按 | C 短按 |
|----------|--------|--------|--------|
| 内容浏览类（仪表/余额/股票/自媒/天天中奖/背单词等） | 翻页（下一张/下一项） | 主操作（刷新/确认/机选/进详情） | 退出返回主菜单 |
| 菜单/列表类（主菜单/本机设置/各模式子菜单） | 选中项上移 | 确认/执行 | 选中项下移（退出走页面内"退出"项） |

当前例外（各模式文档内有标注）：
- **控刷视频**：非运行态 A 长按 = 切换 BLE 设备（全项目唯一保留的长按功能）；
- **摩斯电码**：移植套件内部 B 长按 = 返回子菜单（待后续统一）。

## 四、文档同步规则（任何更新 · 强制）

> 2026-09-01 起全局约定：**任何对项目功能 / 接口 / 结构的更新，必须在同一批改动中同步更新对应文档；文档未同步 = 任务未完成。** 完整对照表见项目根 `AGENTS.md` 与 `doc/project_conventions.md` 第 13 节。

**新增功能模式**（完整动作清单）：
1. 按 [功能开发SOP](功能开发SOP.md) 完成模式开发与注册；
2. 复制 [模式功能文档模板](模式功能文档模板.md) 为 `doc/<功能名>模式功能文档.md`，对照源码逐节填写（按键表务必逐项核实）；
3. 本页"功能模式索引"表追加一行；
4. 同步 README.md 与 [项目目录结构说明](项目目录结构说明.md) 的文档清单。

**修改既有模式**：更新该模式功能文档的对应章节（按键 / 页面 / 数据依赖 / 已知问题）；菜单描述变化时同步 README 功能模块表。

**涉及 framework / settings.json / HTTP 接口 / 全局约定**：同步 [框架架构设计文档](框架架构设计文档.md) 与 `doc/project_conventions.md` 对应章节；涉及接口的同步 README HTTP 表。

**目录 / 文件 / 工具 / Profile 变更**：同步 [项目目录结构说明](项目目录结构说明.md) 与 README 对应段落。

文档更新与代码改动**同批提交**，不留"下次补"。
