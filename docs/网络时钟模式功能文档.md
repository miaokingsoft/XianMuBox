# 网络时钟模式（Net Clock）功能文档

> 模块路径：`src/modes/net_clock.py`（`NetClockMode`，赛博霓虹 · UX 重构版）
> 关联资源：`font/sy_32x32.mpy`（大号数字）、`font/hz_24x24.mpy`（中文）、`framework/weather.py`（天气）、`framework/moon.py`（月相）、`framework/alarm.py`（全局闹钟服务）、`framework/http_server_state.py`（Web 服务探测）、`framework/http_server.py → sync_device_time()`（NTP）
> 配置文件：`settings.json → alarms`（闹钟 3 组，Web 端"闹钟"页签编辑）；时区固定北京时间 UTC+8（不落配置，NTP 同步后按 +8h 修正）
> 构建绑定：`profiles/*.json → {"id": "net_clock", "module": "modes.net_clock", "class": "NetClockMode"}`
> 最近更新：2026-09-01（补充闹钟列表页与全局闹钟服务说明）

## 一、功能概述

网络时钟是桌面摆件的**信息中枢模式**，以赛博霓虹风格呈现时间、天气与工具功能。UX 重构后的核心变化：

1. **六页信息架构**：时钟页（默认）/ 天气页 / 功能菜单 / 秒表 / 定时器 / 闹钟列表，信息按主次拆分，单页不拥挤；
2. **全模块统一按键语义**（符合项目规范 C短按=退出、A=翻页、B=主操作）；
3. **统一视觉框架**：每页固定"顶部标题栏 + 底部 [A]/[B]/[C] 提示栏"，提示标签统一 ASCII（8px 字体不支持中文）。

## 二、页面结构与导航

```
时钟页(默认) --A--> 天气页 --A--> 时钟页
任意主页 --B--> 功能菜单(秒表/定时器/闹钟/刷新天气/返回)
C短按: 秒表/定时器/闹钟/菜单 → 返回上一级; 主页 → 退出模式
```

## 三、按键表（全模块一张表）

| 页面 | A | B | C |
|------|---|---|---|
| 时钟页 | 翻页→天气页 | 开功能菜单 | 退出模式 |
| 天气页 | 翻页→时钟页 | 开功能菜单 | 退出模式 |
| 功能菜单 | 下一项(循环) | 确认 | 返回时钟页 |
| 秒表 | 启动/停止 | 清零(仅停止时) | 返回菜单 |
| 定时器·设置 | 当前位+1 | 下一位 / 末位=开始 | 返回菜单 |
| 定时器·运行 | 暂停/继续 | 重置回设置页 | 取消并返回菜单 |
| 定时器·响铃 | 任意键返回设置页 | 同左 | 同左 |
| 闹钟列表 | 下一组(循环) | 快速开关该组(即改即存) | 返回菜单 |

## 四、各页布局（240×240）

### 4.1 时钟页（数字雨 + 辉光大字 + 秒针盘）

| 区域 | 内容 |
|------|------|
| 动态边框 (4,18,232,214) | 双层描边 + 四角亮标，4 色轮转（400ms） |
| 信息行 y22-40 | 左：天气图标(代码映射) + 天气文字 + 温度；右：城市 + WiFi 状态点 |
| 星期 y52-76 | `hz_24x24` 中文星期，居中 |
| 日期 y84-92 | `YYYY-MM-DD` 8px 青色 |
| 大字 y104-141 | `sy_32x32` HH:MM，四方向暗青辉光，冒号 1Hz 闪烁（只重绘冒号点） |
| 秒针盘 圆心(120,188) r=24 | 青→品红渐变弧（每分钟回绕）+ 外侧白色游标刻线 + 盘内秒数 |
| 提示行 y218-226 | `A:WX B:MENU C:EXIT` |
| 背景 | 数字雨（矩阵绿三级拖尾），以上区域均为雨滴遮罩 |

### 4.2 天气页

心知数字代码 PNG 大图标（`icons/black/{code}@2x.png`，按文件头宽高居中绘制；code 缺失依次回退 99 → 手绘矢量图标）+ 辉光温度大字 + 天气文字(24px)；HUM/AQI/UV 三徽章（数值按等级变色）；月相图标 + 照亮百分比；DAY/YEAR 进度条。

### 4.3 功能菜单

5 项卡片列表：秒表 / 定时器 / 闹钟 / 刷新天气 / 返回。选中项 = 卡片高亮 + 左侧点缀色条 + chevron。

### 4.4 秒表

大字 MM:SS（运行=绿色辉光，停止=白色）+ 十分位小字（10Hz 只刷小字区域）；状态行 READY/RUN/STOP。

### 4.5 定时器

- 设置页：4 位数字（分:秒），光标格反白 + 上下箭头，**单格闪烁重绘**（无整块清屏）；
- 运行页：大字倒计时（≤30s 琥珀 / ≤10s 红且数字闪烁）+ r=40 进度盘**增量收缩**（尾端擦除并还原底环，无每秒闪烁）+ 盘内剩余百分比；
- 响铃：红屏闪 3 次 + TIME UP + 三音旋律，任意键回设置页。

### 4.6 闹钟列表

- 展示 `settings.json → alarms` 的 3 组闹钟：时间大字（`sy_32x32`，未启用置灰）+ 右侧 ON/OFF 状态与重复规则（`日一二三四五六`，单次显示"单次"）；
- A = 下一组（循环），B = 快速开关该组（即改即存 `settings.json`），C = 返回菜单；
- 时间/重复规则的编辑在 **Web 配置页"闹钟"页签**完成（设备端只做查看与快速开关）；
- 时钟页信息行下方有**下一闹钟提示**（`AL 07:30`，仅显示今日将触发的启用项，与左右内容碰撞时省略）。

## 五、后台服务

| 服务 | 行为 |
|------|------|
| NTP 重同步 | 进入模式 5s 后首次；成功后每 6 小时一次，失败 60s 后重试（开机 NTP 失败时的兜底路径，直到校准）；调用 `sync_device_time()`（固定北京时间 UTC+8） |
| 天气刷新 | 缓存 600s，过期自动拉取；菜单"刷新天气"强制刷新 |
| 整点报时 | mm==ss==0 触发：三音蜂鸣 + 屏幕中心三重放射扩散圆环（0.9s 非阻塞），结束后自动重绘当前页 |
| Web 配置轮询 | `_http_poll()` 经 `framework/http_server_state.py` 惰性探测 HTTP 服务是否开启，开启后才加载重型 `http_server` 模块并轮询请求（Web 保存的闹钟 ≤1s 生效），平时零内存开销 |
| 全局闹钟 | 触发/响铃由 `framework/alarm.py` 在 `BaseMode.run()` 全局处理（本模式 loop 无感知）；响铃页阻塞接管，任意键停止，60s 自动静默；单次闹钟触发后自动关闭并落盘 |

## 六、性能与资源

- **全局部重绘**：大字仅分钟变化重绘、秒针盘/进度弧增量绘制、冒号/游标/十分位只刷小块——无整屏清屏闪烁；
- 数字雨约 15-20fps（每帧 ~300 个 fill_rect），低内存机型可设文件头 `RAIN_ENABLED = False` 关闭；
- 页面切换执行 `gc.collect()`；雨滴状态跨页面切换保持连续。

## 七、数据依赖

| 数据 | 来源 | 缺失表现 |
|------|------|----------|
| 时间 | `machine.RTC()`（开机 NTP 已同步） | 异常回退 12:00 |
| 天气 | `framework/weather.py`（心知天气，code/text/temperature 免费可用） | `--` 占位 |
| 湿度/AQI/UV | 同上（免费版为 None） | 徽章显示 `--` |
| 月相 | `framework/moon.py` 本地计算 | MOON -- |
| 闹钟配置 | `settings.json → alarms`（经 `framework/settings.get_alarms()`，每秒沿热加载） | 无提示、不触发 |
| WiFi 状态 | `framework/wifi.py → check_wifi()` | 红点 |
