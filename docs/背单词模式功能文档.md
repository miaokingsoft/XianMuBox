# 背单词模式（Vocab）功能文档

> 模块路径：`src/modes/vocab.py`（`VocabMode`，BaseMode 包装器）+ `src/vocab/` 包（功能实现）
> 关联资源：`font/hanzi_24.py`（中文/标题，全量字库）、`font/italict.py`（英文矢量字体，INDEX/FONT Hershey 格式）、`font/vga1_16x32.py` 等位图降级字体
> 配置文件：无（词库内置，不读 settings.json，不联网）
> 构建绑定：`profiles/full.json → {"id": "vocab", "module": "modes.vocab", "class": "VocabMode"}`
> 最近更新：2026-09-06（修复 vga1_8x16 缺 FONT 导出致真机 KeyError: FONT；字体链加固；中文迁移 hanzi_24；italict 经 font 包导入生效）

---

## 一、功能概述

背单词浏览模式：全屏单页展示英文单词与中文释义，支持手动翻页与自动轮播（UI 1:1 复刻源项目）。

1. **零联网零配置**：981 条词库（`vocab/words_data.py → DanCi`）全部内置；
2. **包装器架构**：`vocab.py` 仅做生命周期包装，`exit()` 时卸载 `vocab.*` 模块并 `gc.collect()`；
3. **自动播放非阻塞**：进度条用 `ticks_ms` 推进（源项目为阻塞内循环），播放期间保持按键响应；
4. **三键适配**：源项目 4 键（A 前翻/B 后翻/C 自动/D 退出）收敛为本项目 3 键规范（A 翻页/B 自动/C 退出）。

## 二、页面结构与导航

单页应用，仅有"手动 / 自动播放"两个状态：

```
手动模式 --B--> 自动播放模式(进度条, 12s/词随机跳词) --B--> 手动模式
C短按: 任何状态 → 退出模式
```

## 三、按键表（全模块一张表）

| 状态 | A | B | C |
|------|---|---|---|
| 手动模式 | 翻下一个词（仅前进，末尾循环回开头） | 开启自动播放（高音确认） | 退出模式 |
| 自动播放模式 | 忽略 | 关闭自动播放 | 退出模式 |

- 无长按/双击手势；操作均有蜂鸣反馈（翻页 900Hz、开自动 1200Hz、关自动 800Hz、退出 1000Hz）。

## 四、各页布局（240×240）

| 区域 | 内容 |
|------|------|
| 标题栏 y0-50 | 黄色标题栏（`CLR_VOCAB_HDR`）+ 图标 + 标题"背单词" |
| 进度条 y51-55 | 自动播放进度（4px，开启时按 elapsed/AUTO_MS 逐像素推进，增量重绘） |
| 内容区 y56-205 | 英文单词（优先 `italict` 矢量字体）+ 中文释义（绿色 `CLR_VOCAB_DEF`，按字体宽度自动换行） |
| 页码 | "当前 / 总数"（8x16 位图字体） |
| 底部按钮 y206-238 | 3 个按钮：翻页 / 自动（开启态高亮）/ 退出；标签汉字**双向居中**（`write_len` 实测宽度水平居中，不可用时按 `MAX_WIDTH` 估算；垂直按 `HEIGHT` 居中，2026-09-06 起） |

> 英文字体降级链：`italict` → `vga1_16x32` → `vga1_8x16` → `vga1_8x8`，位图降级位置统一置于 y=56，避开进度条区域；矢量 `tft.draw()` 首次调用异常时自动永久降级位图 `text()` 路径。
> 各级字体导入均带 `hasattr(mod, 'FONT')` 校验：字体模块存在但缺位图导出时视为不可用，直接降下一级（防驱动 `text()` 抛 KeyError）。

## 五、业务规则（翻页与跳词）

- **手动翻页**：`id = (id + 1) % total`，仅前进方向循环；
- **自动播放**：每词停留约 12s（`AUTO_MS = 12000`，源项目 240×50ms 的等价换算），到时**随机**跳下一个词（`randrange(0, total)`，已修复源项目 `randrange(0,900)` 越界 bug）；
- 进入模式时随机起始词，并 `buttons.clear_events()` 丢弃残留事件/边沿防误触发。

## 六、性能与资源

- `loop()` 内 `gc.collect()` 节流为每 100 帧一次（约 5s，约定文档 gc 规范）；
- 包装器 `exit()` 卸载 `vocab.*` 全部子模块 + `gc.collect()`；`Words.exit()` 同步置空词库大对象引用 `self.abc`；
- 自动播放进度条增量绘制（记录上次像素位置，未变化不重绘）。

## 七、数据依赖

| 数据 | 来源 | 缺失表现 |
|------|------|----------|
| 词库 | `vocab/words_data.py → DanCi`（981 条 `(单词, 中文释义)` 元组，由源项目 danci.txt 自动生成） | 模式不可用（内置，不会发生） |
| 中文/标题 | `font/hanzi_24.py`（GB2312 全区 + ASCII，romfont 数据嵌固件） | 标题/按钮/释义缺字（全量字库，不会发生） |
| 英文单词 | `font/italict.py`（Hershey 矢量，`tft.draw()` 基线坐标 y=76） | 降级位图字体绘制于 y=56 |
| 页码 | `font/vga1_8x16.py`（定宽位图，含 `FONT = memoryview(_FONT)` 导出） | 逐级降级 16x16 → 8x8，全缺时跳过页码 |
