# ESP32-S3 Zero 引脚接线说明

> 适用硬件：ESP32-S3 N8R8（项目主目标，参考设备档案 `devices/esp32s3_n8r8.py`）  
> 最近更新：2026-09-14（I2S 引脚由 15/16/14 调整为 **GPIO38/39/40**，代码已同步；新增 SD 卡 SPI 接线 1/13/17/18；整板全景分配快照见 `doc/完整接线总表.md`）

---

## 最终推荐接线方案（与 `devices/esp32s3_n8r8.py` 严格对齐）

| 屏幕引脚 | 标号 | 连接 ESP32 GPIO | 说明 |
|---------|------|----------------|------|
| 第1针 | **GND** | **GND** | 电源地 |
| 第2针 | **VCC** | **3.3V** | 屏幕电源（ST7789 通常 3.3V） |
| 第3针 | **SCL** | **GPIO12** | SPI 时钟 |
| 第4针 | **SDA** | **GPIO11** | SPI 数据 (MOSI) |
| 第5针 | **RES** | **GPIO8** | 复位 |
| 第6针 | **DC** | **GPIO9** | 数据/命令选择 |
| 第7针 | **CS** | **GPIO10** | 片选 |
| 第8针 | **BLK** | **GPIO7** | 背光（PWM 调光，可写直接接 3.3V 常亮） |

## 蜂鸣器 + 3个按钮 + RGB LED 接线

| 外设 | 连接 ESP32 GPIO | 说明 |
|------|----------------|------|
| **蜂鸣器 (信号)** | **GPIO6** | 有源蜂鸣器，**低电平触发**（高电平=静音），PWM 驱动可调音量 |
| **按钮 A** | **GPIO5** | 另一端接 GND，内部上拉 |
| **按钮 B** | **GPIO4** | 另一端接 GND，内部上拉 |
| **按钮 C** | **GPIO3** | 另一端接 GND，内部上拉 |
| **WS2812 RGB LED (DIN)** | **GPIO21** | 摩尔斯电码模式指示灯（`LED_PIN`） |
| **MAX98357A BCLK** | **GPIO38** | I2S 位时钟（`I2S_BCLK`；2026-09-13 由 GPIO15 调整，底边焊盘三线相邻集中走线） |
| **MAX98357A LRC** | **GPIO39** | I2S 左右声道字时钟（`I2S_LRC`，由 GPIO16 调整） |
| **MAX98357A DIN** | **GPIO40** | I2S 串行数据（`I2S_DIN`，由 GPIO14 调整） |
| **MAX98357A VIN** | **3.3V** | 3.3V 供电（4Ω 喇叭约 1.8W；接 5V 可达 3W 满功率） |
| **MAX98357A GND** | **GND** | 共地 |
| **MAX98357A SD** | **3.3V** | 高电平=功放开启（>1.4V 输出左声道）；接 GND=静音 |
| **MAX98357A GAIN** | 悬空 | 默认增益 9dB；模块跳线焊盘可切 12/15dB |
| **喇叭** | MAX98357A 绿色端子 ± | 4Ω 或 8Ω 3W 小喇叭 |
| **SD 卡 CS** | **GPIO1** | 片选（`SD_CS`，v1.9 SD 卡接入，独立 SPI(2) 总线） |
| **SD 卡 SCK** | **GPIO18** | SPI 时钟（`SD_SCK`，与屏幕 SPI(1) 完全隔离） |
| **SD 卡 MOSI** | **GPIO17** | 主出从入（`SD_MOSI`） |
| **SD 卡 MISO** | **GPIO13** | 主入从出（`SD_MISO`） |
| **SD 卡 VCC / GND** | **3.3V / GND** | 带稳压模块也可接 5V；**不支持热插拔**（插拔断电）；TF 卡须 FAT32 |

> 按键统一约定（2026-08-30）：内容浏览类页面 A 短按=翻页、B 短按=主操作、C 短按=返回主菜单；菜单/列表类页面 A=上移、B=确认、C=下移，退出走"退出"项。不使用长按（唯一例外：控刷视频 A 长按=切设备）。  
> 蜂鸣器 (-) 接 GND；HAL 中 `Buzzer` 按低电平触发设计，空闲时输出高电平保持静音。  
> WS2812 的 VCC 接 3.3V/5V、GND 接 GND，DIN 接 GPIO21。  
> SD 卡由 `framework/sdcard.py` 在开机时自动挂载到 `/sd`（独立 SPI(2)，20MHz 失败自动降 10MHz 重试；失败静默不阻塞启动）；诊断脚本 `tests/sd_diag.py`，方案见 `doc/SD卡模块实施方案.md`。

## 完整接线汇总图

```
┌─────────────────────────────────────────────────────────────────┐
│                  ESP32-S3 N8R8 开发板                           │
│                                                                 │
│  屏幕 GND ──────── GND                                         │
│  屏幕 VCC ──────── 3.3V                                        │
│  屏幕 SCL ──────── GPIO12 (SPI CLK)                            │
│  屏幕 SDA ──────── GPIO11 (SPI MOSI)                           │
│  屏幕 RES ──────── GPIO8  (复位)                                │
│  屏幕 DC  ──────── GPIO9  (数据/命令)                           │
│  屏幕 CS  ──────── GPIO10 (片选)                                │
│  屏幕 BLK ──────── GPIO7  (PWM 调光)                           │
│                                                                 │
│  蜂鸣器 (+) ───── GPIO6  (PWM 驱动)                              │
│  蜂鸣器 (-) ───── GND                                           │
│                                                                 │
│  按钮 A ────────── GPIO5  ── 按键 ── GND                       │
│  按钮 B ────────── GPIO4  ── 按键 ── GND                       │
│  按钮 C ────────── GPIO3  ── 按键 ── GND                       │
│                                                                 │
│  WS2812 DIN ───── GPIO21 (RGB LED，摩尔斯电码指示灯)            │
│  WS2812 VCC ───── 3.3V / 5V                                    │
│  WS2812 GND ───── GND                                          │
│                                                                 │
│  MAX98357A BCLK ── GPIO38 (I2S 位时钟, v1.9 由 15 调整)         │
│  MAX98357A LRC ─── GPIO39 (I2S 字时钟, 由 16 调整)              │
│  MAX98357A DIN ─── GPIO40 (I2S 数据, 由 14 调整)                │
│  MAX98357A VIN ─── 3.3V (功放供电)                              │
│  MAX98357A SD ──── 3.3V (高电平=开启)                           │
│  MAX98357A GAIN ── 悬空 (默认 9dB)                              │
│  MAX98357A GND ─── GND                                          │
│  喇叭 ± ────────── MAX98357A 绿色端子 (4Ω/8Ω 3W)                │
│                                                                 │
│  SD 卡 CS ───────── GPIO1  (片选, 独立 SPI(2))                  │
│  SD 卡 SCK ──────── GPIO18 (SPI 时钟)                           │
│  SD 卡 MOSI ─────── GPIO17 (主出从入)                           │
│  SD 卡 MISO ─────── GPIO13 (主入从出)                           │
│  SD 卡 VCC/GND ──── 3.3V / GND (不支持热插拔, 卡须 FAT32)       │
└─────────────────────────────────────────────────────────────────┘
```

## 屏幕参数（来自设备档案）

```python
W, H         = 240, 240
ROTATION     = 2  # 180° 翻转
BUFFER_SIZE  = 320 * 40 * 2   # S3 有 PSRAM，buffer 更大以提升刷屏流畅度
CHIP         = "esp32s3"
HAS_BLE      = True
HAS_PSRAM    = True
MAX_FONT_SIZE= 32
```

若需调整为不同方向/分辨率，编辑 `devices/esp32s3_n8r8.py` 后执行 `python tools/build.py --profile <X> --device esp32s3_n8r8` 重新生成 `config.py` 即可，框架代码无需修改。
