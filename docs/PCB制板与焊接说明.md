# 闲沐盒子 PCB 制板与焊接说明

> **XianMuBox v3.0** — 三板分体架构，嘉立创 EDA 专业版设计  
> 工程源文件：`XianMuBoxv3.0_2026-09-20.epro2`（含 3 块子板原理图）

---

## 一、架构总览

闲沐盒子采用 **三板分体** 设计，通过 FPC 软排线级联，降低单块板面积、方便维修更换：

| 序号 | 板名 | 核心功能 | 关键器件 |
|:---:|------|---------|--------|
| ① | **按钮接线板** | 3 颗用户按键 + 预留 1 路 GPIO | 按键 ×3、3P 母排、6P FPC座 |
| ② | **TFT 转接板（带 SD 卡）** | ST7789 240×240 彩屏驱动 + MicroSD 卡槽 | 屏幕8P 母排、SD 卡座、6P排针、6P+16P FPC 座 |
| ③ | **主控板（ESP32S3-Zero 贴片）** | 微雪 ESP32-S3-Zero 模块贴片焊接 + I2S 功放 | ESP32-S3-Zero、MAX98357A、蜂鸣器、16P FPC 座 |

三板之间的连接关系（级联拓扑）：

```
① 按钮板  ── 3P 母排 ──▶  ② TFT转接板  ── 16P FPC ──▶  ③ 主控板
(3颗按键)                 (屏幕+SD卡)               (ESP32-S3-Zero+功放+蜂鸣器)
```

| 连接段 | 线缆 | 传输信号 |
|-------|------|--------|
| ① → ② | 3P 母排 | GPIO3/4/5（三颗按键信号） |
| ② → ③ | 16P FPC 软线 | 屏幕 SPI（GPIO7~12）、SD SPI（GPIO1/13/17/18）、3.3V/GND、透传 GPIO3~5 |

> **信号流向**：按钮板的 3 颗按键信号经 3P 母排到达 TFT 转接板，TFT 板将自身屏幕/SD 信号与透传的按键信号一起经 16P FPC 汇总到主控板。主控板是唯一的电源入口、ESP32 核心，蜂鸣器也位于主控板上。

## 二、板 ①：按钮接线板

### 功能

提供用户交互输入（3 颗按键），并预留 1 路空闲 GPIO 供扩展。板面仅提供 1 路 3P 母排用于连接 TFT 转接板，无蜂鸣器（蜂鸣器在主控板上）。

### 器件清单

| 器件 | 数量 | 规格 | 备注 |
|------|:---:|------|------|
| 轻触按键 | 3 | 12×12×8mm | 另一端接 GND，使用 ESP32 内部上拉 |
| 3P 母排 | 1 | 3pin 2.54mm 排母 | 预留 |
| 6P FPC座 | 1 | 0.5mm FPC母座 | 连接 TFT 转接板（按键信号输出） |

### 引脚分配

| 按键/器件 | 连接 GPIO | 说明 |
|----------|----------|------|
| 按钮 A | **GPIO5** | 内容浏览：翻页 / 菜单列表：上移 |
| 按钮 B | **GPIO4** | 内容浏览：主操作 / 菜单列表：确认 |
| 按钮 C | **GPIO3** | 内容浏览：退出返回 / 菜单列表：下移 |
| **预留 GPIO** | **GPIO2** | 唯一空闲 ADC1 引脚，可接模拟传感器/扩展 |

### 3P 母排输出（→ TFT 转接板）

按钮板通过 **3P 母排** 将 3 颗按键信号送到 TFT 转接板，再由 TFT 板经 16P FPC 汇总到主控板。

| 3P 母排 Pin | 信号 | 说明 |
|:----------:|------|------|
| 1 | GPIO3 | 按键 C |
| 2 | GPIO4 | 按键 B |
| 3 | GPIO5 | 按键 A |

> 按键电源（3.3V）与地（GND）通过按钮板本地回路解决，无需经排线传输。

### 设计要点

- 按键使用 ESP32-S3 **内部上拉**，外部无需额外上拉电阻，按键另一端统一接 GND
- 预留的 GPIO2 是 **唯一空闲的 ADC1 引脚**，优先留给模拟用途（如外接光敏电阻测环境亮度）
- 板子体积极小，可随外壳固定在按键位置附近
- 3P 母排为标准 2.54mm 间距排母，与 TFT 转接板上对应的 3P 排针对接

## 三、板 ②：TFT 转接板（带 SD 卡）

### 功能

承载 ST7789 240×240 彩色 SPI 屏幕的接口电路，同时焊接 MicroSD 卡座用于新闻存档/回听。屏幕与 SD 卡各占一路独立 SPI 总线，互不干扰。

### 器件清单

| 器件 | 数量 | 规格 | 备注 |
|------|:---:|------|------|
| ST7789 240×240 屏幕 | 1 | 8pin SPI 接口 | 需另购，非贴片 |
| MicroSD 卡座 | 1 | 贴片 MicroSD/T 卡座 | 需焊接到板上 |
| 6P 排针 | 1 | 0.5mm FPC座 | 通过6P 反向软排与按钮板连接 |
| 16P FPC 座 | 1 | 16pin 0.5mm 间距 FPC 连接器 | 通过 16P FPC 软线连接主控板 |

### 屏幕接口（SPI1，40MHz）

| 屏幕引脚 | 连接 ESP32 GPIO | 说明 |
|---------|----------------|------|
| GND | GND | 电源地 |
| VCC | 3.3V | 屏幕电源 |
| SCL | **GPIO12** | SPI 时钟（SPI1） |
| SDA | **GPIO11** | SPI 数据 MOSI |
| RES | **GPIO8** | 复位 |
| DC | **GPIO9** | 数据/命令选择 |
| CS | **GPIO10** | 片选 |
| BLK | **GPIO7** | 背光（PWM 调光；直接接 3.3V 则常亮） |

### SD 卡接口（SPI2，独立总线）

| SD 卡引脚 | 连接 ESP32 GPIO | 说明 |
|----------|----------------|------|
| CS | **GPIO1** | 片选 |
| SCK | **GPIO18** | SPI 时钟（独立 SPI2，与屏幕 SPI1 隔离） |
| MOSI | **GPIO17** | 主出从入 |
| MISO | **GPIO13** | 主入从出 |
| VCC | 3.3V | 带稳压模块也可接 5V |
| GND | GND | 共地 |

### 设计要点

- **SD 卡座需手工焊接**：MicroSD 卡座为贴片元件，引脚间距 1.27mm，需用烙铁或热风枪焊接
- SD 卡使用独立 SPI2 总线，与屏幕 SPI1 完全隔离，二者可同时工作互不干扰
- SD 卡 **不支持热插拔**，换卡须断电操作
- TF/MicroSD 卡须格式化为 **FAT32**（64GB 及以上默认 exFAT 需重新格式化）
- 屏幕 BLK 背光引脚支持 PWM 调光，固件中已实现亮度调节；若不需要调光可直接接 3.3V 常亮
- 屏幕排针通常为 8pin 1.27mm 间距，注意方向标识
- TFT 板是整条链路的 **中间枢纽**：一端通过 接收按钮板按键信号，另一端通过 16P FPC 将所有信号（屏幕 + SD 卡 + 透传的按键）汇总送往主控板

## 四、板 ③：主控板（ESP32S3-Zero 贴片）

### 功能

整台闲沐盒子的核心——微雪 ESP32-S3-Zero（N8R8）模块通过 **贴片焊接（SMT）** 固定到板上，板上集成 MAX98357A I2S 功放电路、有源蜂鸣器、USB-C 供电电路和 3.3V 稳压，以及连接 TFT 转接板的 16P FPC 座。

### 器件清单

| 器件 | 数量 | 规格 | 备注 |
|------|:---:|------|------|
| 微雪 ESP32-S3-Zero (N8R8) | 1 | 8MB Flash + 8MB PSRAM | **SMT 贴片焊接**，非排针插接 |
| MAX98357A 模块 | 1 | I2S D 类功放 | 焊接在板上，接直径 20mm 4Ω/8Ω 3W 小喇叭 |
| 有源蜂鸣器 | 1 | 3.3V 有源蜂鸣器 | 低电平触发，接 GPIO6 |
| 16P FPC 座 | 1 | 16pin 0.5mm 间距 | 接收 TFT 转接板汇总信号 |

### ESP32-S3-Zero 模块焊接

微雪 ESP32-S3-Zero 是一款邮票孔/ Castellated 模块，需要 **SMT 贴片焊接** 到主控板上：

| 模块参数 | 值 |
|---------|---|
| 主控芯片 | ESP32-S3 双核 LX7 @ 240MHz |
| Flash | 8MB |
| PSRAM | 8MB（Octal） |
| WiFi | 802.11 b/g/n 2.4GHz |
| Bluetooth | BLE 5.0 |
| 封装 | 邮票孔 Castellated，可 SMT 回流焊 |

> ⚠️ **贴片焊接注意**：ESP32-S3-Zero 为邮票孔模块，建议使用钢网 + 回流焊或热风枪焊接。手工烙铁需有经验，注意不要短路相邻引脚。

### I2S 功放电路

| MAX98357A 引脚 | 连接 ESP32 GPIO | 说明 |
|---------------|----------------|------|
| BCLK | **GPIO38** | I2S 位时钟 |
| LRC | **GPIO39** | I2S 左右声道字时钟 |
| DIN | **GPIO40** | I2S 串行数据 |
| VIN | 3.3V | 功放供电（接 5V 可达 3W 满功率） |
| SD（使能） | 3.3V | 高电平 = 功放开启；接 GND = 静音 |
| GAIN | 悬空 | 默认增益 9dB（模块跳线可切 12/15dB） |
| GND | GND | 共地 |
| 喇叭 ± | 绿色端子 | 接 4Ω 3W 小喇叭 |

### 供电设计

```
USB-C 5V ──▶ Zero板载USB ──▶ 3.3V 输出
    │                                        │
    ├──▶ 5V 母线（可选供 MAX98357A 满功率）    ├──▶ ESP32-S3-Zero 3V3 输入
    │                                        ├──▶ ST7789 屏幕 VCC
    │                                        ├──▶ SD 卡 VCC
    │                                        └──▶ 蜂鸣器 VCC（经按钮板）
    └──▶ GND 共地
```

- USB-C 5V 为单一供电入口
- 所有 3.3V 设备统一取自主板 LDO 输出的 3V3
- MAX98357A 接 3.3V 时驱动 4Ω 喇叭约 1.8W；如需 3W 满功率可将 VIN 接 5V

### 16P FPC 输入（← TFT 转接板）

主控板通过 **16P FPC 软线** 接收来自 TFT 转接板的全部信号（含屏幕 SPI、SD 卡 SPI、透传的按键信号）。蜂鸣器直接焊接在主控板上，不经过 FPC 传输。

| 16P FPC 线序 | 信号 | 来源 | 说明 |
|:----------:|------|------|------|
| 1 | GND | — | 共地 |
| 2 | 3.3V | LDO 输出 | 给 TFT 板 + 按钮板供电 |
| 3 | GPIO1 | SD 卡 | SD 卡 CS |
| 4 | GPIO7 | 屏幕 | BLK 背光 |
| 5 | GPIO8 | 屏幕 | RES 复位 |
| 6 | GPIO9 | 屏幕 | DC 数据/命令 |
| 7 | GPIO10 | 屏幕 | CS 片选 |
| 8 | GPIO11 | 屏幕 | SDA/MOSI |
| 9 | GPIO12 | 屏幕 | SCL/SCK |
| 10 | GPIO13 | SD 卡 | MISO |
| 11 | GPIO3 | 按钮板（透传） | 按键 C |
| 12 | GPIO4 | 按钮板（透传） | 按键 B |
| 13 | GPIO5 | 按钮板（透传） | 按键 A |
| 14 | — | 空闲 | 预留（原蜂鸣器信号位） |
| 15 | GPIO17 | SD 卡 | MOSI |
| 16 | GPIO18 | SD 卡 | SCK |

> 线序以实际 EDA 工程为准，上表为逻辑分配参考。

### 设计要点

- ESP32-S3-Zero 模块 **邮票孔 SMT 焊接**，焊接后不可轻易拆卸，请确认方向后再焊
- 板载 WS2812 RGB LED 接 GPIO21，用于摩斯电码模式指示灯等状态反馈
- USB-C 口既供电又支持数据通信（刷机用 esptool）
- 16P FPC 座为 0.5mm 间距，注意插入方向（触点朝向）
- GPIO43/44（UART0 TX/RX）保留为调试串口，引出焊盘但不接默认外设
- GPIO41/42 为空闲备用（注意：这两个是外部 JTAG 复用脚）

## 七、焊接顺序建议

推荐按以下顺序焊接，由小到大、由低到高：

1. **主控板 ③**
   - 先焊 USB-C 座、LDO 及被动元件
   - 再焊 ESP32-S3-Zero 模块（SMT 邮票孔，注意方向）
   - 最后焊 MAX98357A 模块、蜂鸣器、16P FPC 座、喇叭端子
   - 可选：板载 WS2812 LED

2. **TFT 转接板 ②**
   - 焊 SD 卡座（贴片，1.27mm 间距，注意方向）
   - 焊 3P 排针（来自按钮板）
   - 焊 16P FPC 座（连接主控板）
   - 焊屏幕排针（8pin 1.27mm）

3. **按钮接线板 ①**
   - 焊 3 颗按键
   - 焊 3P 母排（连接 TFT 板）

焊接完成后用万用表检查各电源轨对地是否短路，确认无误后再通电。
